# Лабораторная работа № 1. Библиотека обработки изображений

## 1. Цель работы

Цель работы — разработать библиотеку обработки изображений на языке Python, реализующую восемь фильтров с использованием базовых матричных операций NumPy.

В рамках работы реализованы геометрическое и цветовые преобразования, а также художественные эффекты: изменение размера изображения, перевод в оттенки серого, сепия с виньеткой, выцветание, плёночная цветопередача, белая матовая рамка, состаривание фотографии и неоновое свечение контуров.

Основные алгоритмы обработки реализованы самостоятельно с использованием NumPy. Библиотека OpenCV применяется для чтения и сохранения изображений.

## 2. Используемые технологии

- **Python** — язык программирования.
- **NumPy** — работа с массивами изображений и выполнение математических операций над пикселями.
- **OpenCV** — чтение и сохранение изображений.
- **argparse** — обработка аргументов командной строки.
- **pathlib** — работа с путями к файлам.

Цветное изображение представляется трёхмерным массивом размера $H \times W \times 3$, где $H$ — высота, $W$ — ширина, а три компонента соответствуют цветовым каналам.

OpenCV хранит цветные изображения в порядке **BGR**: синий, зелёный, красный. Значения каналов обычно находятся в диапазоне от 0 до 255.

В формулах ниже $I$ обозначает исходное изображение или пиксель, а $I'$ — результат обработки. Для выполнения вычислений значения пикселей преобразуются в тип `float32`. После обработки результат ограничивается диапазоном от 0 до 255 и преобразуется в `uint8`.

## 4. Математическое обоснование фильтров

### 4.1. Resize — изменение размера изображения

Для изменения разрешения используется метод ближайшего соседа (*Nearest Neighbor*).

Пусть исходное изображение имеет размеры $H \times W$, а новое — $H' \times W'$.

Для каждого пикселя нового изображения вычисляются координаты соответствующего пикселя исходного изображения:

\[
x_s=\left\lfloor x\frac{W}{W'}\right\rfloor
\]

\[
y_s=\left\lfloor y\frac{H}{H'}\right\rfloor
\]

Тогда значение пикселя результата определяется выражением:

\[
I'(y,x)=I(y_s,x_s)
\]

Здесь $x,y$ — координаты пикселя нового изображения, а $x_s,y_s$ — координаты пикселя исходного изображения.

В реализации для вычисления индексов используются `np.arange`, масштабирование координат, преобразование к целочисленному типу и ограничение индексов допустимым диапазоном. Затем пиксели выбираются посредством индексирования NumPy-массива.

Если `--width` или `--height` не заданы, соответствующий размер рассчитывается с использованием коэффициента `--scale-x` или `--scale-y`. Значения коэффициентов по умолчанию равны `0.5`. Если задан только один размер, второй рассчитывается с использованием своего коэффициента масштабирования по умолчанию, поэтому сохранение пропорций автоматически не гарантируется.

**Обоснование выбора алгоритма:** метод ближайшего соседа прост и позволяет реализовать изменение размера без использования готового `cv2.resize`. Он не вычисляет промежуточные значения цветов, поэтому при увеличении изображения могут появляться ступенчатые границы.

### 4.2. Grayscale — преобразование в оттенки серого

Для перевода цветного изображения в оттенки серого вычисляется яркость каждого пикселя.

Используется взвешенная сумма цветовых каналов:

\[
Y=0.114B+0.587G+0.299R
\]

Здесь $B$, $G$ и $R$ — значения синего, зелёного и красного каналов соответственно, а $Y$ — рассчитанная яркость.

Коэффициенты различаются, поскольку цветовые каналы вносят неодинаковый вклад в воспринимаемую яркость изображения.

В программе каждый канал извлекается из массива и преобразуется в `float32`. Затем вычисляется яркость по приведённой формуле. Результат представляет собой двумерный массив `uint8`.

**Обоснование:** взвешенное преобразование сохраняет различия в яркости объектов лучше, чем простое арифметическое среднее трёх каналов. В результате каждый пиксель представлен одним значением яркости вместо трёх цветовых компонентов.

### 4.3. Antique — эффект сепии с виньеткой

Эффект Antique состоит из двух этапов: преобразования цветопередачи в сепию и добавления радиальной виньетки.

Сначала для каждого пикселя рассчитываются новые значения цветовых каналов:

\[
R'=0.393R+0.769G+0.189B
\]

\[
G'=0.349R+0.686G+0.168B
\]

\[
B'=0.272R+0.534G+0.131B
\]

Матричное преобразование изменяет соотношение исходных цветовых компонентов, придавая изображению тёплый коричневатый оттенок.

Затем формируется радиальная маска виньетки. Для каждого пикселя рассчитывается расстояние до центра изображения в нормированных координатах:

\[
d(x,y)=\sqrt{x^2+y^2}
\]

На основе расстояния строится маска затемнения:

\[
V(x,y)=\left(\operatorname{clip}\left(\frac{d(x,y)-0.4}{0.6},0,1\right)\right)^{1.5}v
\]

Маска равна нулю в центральной области и постепенно увеличивается по направлению к краям. Её интенсивность дополнительно регулируется коэффициентом силы виньетки. В реализации используется значение `vignette_strength`, по умолчанию равное `0.4`.

Итоговое изображение получается затемнением преобразованного изображения в соответствии с радиальной маской. Расчёты выполняются с учётом порядка каналов BGR, используемого OpenCV.

**Обоснование:** сепия создаёт характерную тёплую цветовую стилизацию, а радиальная виньетка затемняет периферию изображения. Совместное применение этих операций усиливает эффект старой фотографии.

### 4.4. Fade Color — эффект выцветания

Фильтр смешивает исходный пиксель с заданным цветом.

Математически операция определяется выражением:

\[
I'=(1-\alpha)I+\alpha C
\]

где:

- $I$ — исходный пиксель;
- $C$ — заданный цвет;
- $\alpha$ — интенсивность эффекта, от 0 до 1;
- $I'$ — результат смешивания.

При $\alpha=0$ изображение остаётся неизменным. При $\alpha=1$ все пиксели заменяются заданным цветом. Промежуточные значения создают плавное смешивание исходного изображения с цветом выцветания.

Цвет, передаваемый через командную строку, задаётся в порядке RGB. Поскольку изображение OpenCV хранится в порядке BGR, перед вычислениями порядок компонент цвета меняется на обратный.

В программе вычисления выполняются сразу над массивами NumPy, без отдельного цикла по каждому пикселю.

**Обоснование:** линейное смешивание позволяет управлять интенсивностью эффекта одним параметром и создавать равномерное цветовое выцветание изображения.

### 4.5. Film — плёночная цветопередача

Фильтр Film реализует стилизованную плёночную цветопередачу. В отличие от простого изменения отдельных каналов, преобразование учитывает яркость исходного пикселя и использует набор цветовых уровней для формирования нового оттенка.

Сначала для каждого пикселя рассчитывается яркость:

\[
Y=0.114B+0.587G+0.299R
\]

Затем яркость преобразуется с изменением контраста:

\[
Y_c=\operatorname{clip}\left(1.2(Y-128)+128,0,255\right)
\]

Для преобразования яркости используется кусочно-линейная интерполяция (`np.interp`). Заданы опорные уровни яркости:

Опорные уровни яркости: `0, 50, 115, 185, 255`.

Для каждого цветового канала используется собственная палитра значений:

Палитра синего канала B: `5, 15, 45, 90, 190`.

Палитра зелёного канала G: `3, 8, 30, 105, 220`.

Палитра красного канала R: `5, 25, 115, 220, 255`.

По преобразованной яркости интерполируются новые значения синего, зелёного и красного каналов. Таким образом, одному и тому же уровню яркости соответствуют разные цветовые компоненты, формирующие заданную плёночную палитру.

Дополнительно в реализации используются маски, учитывающие избыточность синего канала и насыщенность цвета. Они позволяют скорректировать отдельные области изображения перед смешиванием с исходником.

Полученное цветовое преобразование смешивается с исходным изображением с помощью параметра `strength`:

\[
I_f=(1-s)I+sT
\]

где $s$ — сила плёночного эффекта.

После цветокоррекции может добавляться случайное зерно:

\[
I'=I_f+\varepsilon
\]

\[
\varepsilon\sim\mathcal{N}(0,\sigma^2)
\]

Значение $\sigma$ задаётся параметром `noise`. В реализации зерно генерируется отдельно для каждого пикселя и одинаково добавляется к трём цветовым каналам этого пикселя.

**Обоснование:** плёночная цветопередача формируется не только добавлением шума, но и нелинейным преобразованием яркости с помощью цветовых палитр. Смешивание с оригиналом позволяет регулировать выраженность стилизации, а зерно добавляет характерную текстуру аналоговой фотографии.

### 4.6. Matte — белая матовая рамка

Фильтр создаёт мягкую белую овальную рамку по краям изображения.

Сначала для каждого пикселя рассчитывается расстояние до центра изображения. Координаты нормируются, чтобы маска могла быть рассчитана независимо от абсолютного разрешения.

Расстояние определяется формулой:

\[
d(x,y)=\sqrt{x^2+y^2}
\]

На основе расстояния и параметра радиуса строится маска:

\[
t=\operatorname{clip}\left(\frac{d-r}{1-r},0,1\right)
\]

\[
M=s\cdot t^p
\]

где:

- $r$ — радиус центральной области;
- $s$ — сила эффекта;
- $p$ — показатель степени маски, управляющий скоростью нарастания эффекта;
- $M$ — маска, определяющая интенсивность белой рамки.

Затем исходное изображение смешивается с белым цветом:

\[
I'=(1-M)I+255M
\]

Если $M=0$, пиксель сохраняет исходный цвет. Если $M=1$, пиксель становится белым.

По мере удаления от центральной области маска увеличивается, и изображение плавно смешивается с белым цветом. Параметр `radius` задаёт размер центральной области, которая остаётся практически неизменной. Параметр `strength` регулирует интенсивность рамки, а `softness` — характер нарастания маски.

При значении `softness` меньше 1 маска нарастает быстрее в начале перехода, при значении больше 1 — медленнее вблизи границы центральной области.

**Обоснование:** маска позволяет управлять эффектом в зависимости от положения каждого пикселя. Использование расстояния до центра формирует овальную рамку, а показатель степени `softness` регулирует скорость нарастания маски.

### 4.7. Noise — эффект старой фотографии

Фильтр имитирует визуальные дефекты старой фотографии с помощью затемнения, случайного зерна, светлых и тёмных царапин, пыли и цветовой засветки. Для зерна генерируется одно случайное значение на пиксель с формой массива $H\times W\times1$; оно добавляется сразу ко всем трём каналам BGR. Поэтому зерно не создаёт независимых цветовых отклонений между каналами одного пикселя.

#### Затемнение и зерно

Сначала изображение немного затемняется:

\[
I_1=0.88I
\]

Затем добавляется случайное зерно:

\[
I_2=I_1+\varepsilon,\qquad
\varepsilon\sim\mathcal{N}(0,(24a)^2)
\]

где $a$ — параметр `amount` (в командной строке — `--noise`).

#### Формирование царапин

Создаются две двумерные маски: для светлых и тёмных царапин. Число генерируемых линий зависит от площади изображения и параметра `scratch_density`. Царапины строятся как последовательности точек с небольшими случайными изменениями направления, изгиба и яркости. Используются короткие, средние и длинные линии.

Маски сглаживаются собственной функцией `box_blur`. Она дополняет массив граничными значениями и вычисляет среднее в окрестности $3\times3$:

\[
B(x,y)=\frac{1}{9}
\sum_{i=-1}^{1}\sum_{j=-1}^{1}
M(x+i,y+j)
\]

После сглаживания исходная и сглаженная маски смешиваются:

\[
L=0.72L_0+0.28B_L,
\qquad
D=0.70D_0+0.30B_D
\]

где $L_0$ и $D_0$ — исходные маски светлых и тёмных царапин, а $B_L$ и $B_D$ — их сглаженные версии. Для светлых царапин дополнительно применяется небольшая случайная вариация текстуры.

Светлые царапины усиливают значения каналов BGR с коэффициентами 58, 64 и 68 соответственно. Тёмные царапины вычитают из каждого канала величину, пропорциональную маске, с коэффициентом 28.

#### Добавление пыли

В случайных координатах создаются небольшие светлые пятна радиусом от 1 до 3 пикселей. Яркость пятна убывает с расстоянием от его центра, поэтому пыльные точки имеют мягкие края.

#### Цветовая засветка

Засветка формируется в нижней левой части изображения. Для каждого пикселя вычисляется расстояние до заданной области в нормированных координатах. На его основе строится основная маска, которая объединяется с дополнительной экспоненциальной составляющей. Полученная маска трижды сглаживается функцией `box_blur`.

К каналам изображения добавляются разные значения, пропорциональные маске засветки $L(x,y)$:

\[
B'=B+45L
\]

\[
G'=G+110L
\]

\[
R'=R+190L
\]

Такое соотношение каналов создаёт оранжево-красный световой блик.

**Обоснование:** эффект старой фотографии формируется сочетанием нескольких независимых типов дефектов: зерна, неровных царапин, пыли и локальной цветовой засветки. Случайные элементы генерируются заново при каждом запуске, поэтому результаты могут немного различаться.

### 4.8. Neon — неоновое свечение контуров

Фильтр выделяет выраженные контуры изображения и формирует вокруг них цветное многослойное свечение.

#### Шаг 1. Расчёт яркости

Цветное изображение преобразуется в карту яркости:

\[
Y=0.114B+0.587G+0.299R
\]

Это позволяет анализировать изменения интенсивности изображения независимо от отдельных цветовых компонентов.

#### Шаг 2. Предварительное сглаживание

К карте яркости дважды применяется функция `fast_blur`, выполняющая усреднение в окрестности $3\times3$. Это уменьшает влияние мелких деталей и случайных колебаний яркости перед выделением контуров.

#### Шаг 3. Вычисление градиента

Для выделения границ используется оператор Собеля. Горизонтальная и вертикальная составляющие градиента вычисляются с помощью соответствующих масок:

\[
G_x=K_x*Y,\qquad G_y=K_y*Y
\]

В реализации свёртка выполняется над дополненным по краям массивом NumPy.

Величина градиента определяется выражением:

\[
E(x,y)=\sqrt{G_x(x,y)^2+G_y(x,y)^2}
\]

Большие значения $E$ соответствуют резким изменениям яркости, которые часто возникают на границах объектов.

#### Шаг 4. Нормализация контуров

В качестве нижней и верхней границ нормализации используются 90-й и 99.5-й процентили величины градиента. Значения между этими границами переводятся в диапазон от 0 до 1:

\[
E_n=\operatorname{clip}
\left(
\frac{E-P_{90}}{P_{99.5}-P_{90}},0,1
\right)
\]

Если верхний процентиль не превышает нижний, маска контуров заполняется нулями. После нормализации применяется степенное преобразование:

\[
E_f=E_n^{1.5}
\]

Оно усиливает выраженность наиболее ярких контуров.

#### Шаг 5. Формирование многослойного свечения

На основе маски контуров создаётся цветной слой свечения. Для него используются BGR-компоненты с коэффициентами 220, 15 и 255. Отдельно формируется яркое ядро контура с компонентами 255, 175 и 255.

Для цветного слоя рассчитываются три варианта размытия:

- ближнее свечение с фиксированным масштабом $\sigma=3.5$;
- среднее свечение с масштабом $\max(2, 2.5b)$;
- широкое свечение с масштабом $\max(4, 5b)$,

где $b$ — параметр `blur`, передаваемый из командной строки как `--neon-blur`.

Функция `gaussian_blur` аппроксимирует гауссово размытие тремя последовательными проходами усреднения по горизонтали и вертикали. Для эффективного вычисления скользящих сумм используются накопительные суммы `np.cumsum`.

#### Шаг 6. Сборка результата

Исходное изображение ослабляется коэффициентом 0.65. Затем к нему прибавляются широкое, среднее и ближнее свечение, а также яркое ядро контуров:

\[
I'=0.65I+
5sG_w+
2.5sG_m+
1.5sG_n+
sC
\]

где $s$ — сила свечения (`strength`), $G_w$, $G_m$, $G_n$ — слои широкого, среднего и ближнего свечения, а $C$ — яркое ядро контуров.

Итоговые значения ограничиваются диапазоном от 0 до 255.

**Обоснование:** оператор Собеля выделяет границы объектов по изменению яркости. Несколько масштабов размытия формируют ореол разной ширины, а отдельное яркое ядро сохраняет визуально выраженную линию контура. Это позволяет получить более объёмное свечение, чем при простом размывании одной маски.

Например, в `color.py` у `Film.apply` значения по умолчанию `strength=0.8` и `noise=3`, но при запуске через CLI передаются `--strength 0.7` и `--film-noise 8.0`. Параметры применяются к соответствующему фильтру. Параметры, не используемые выбранным фильтром, не влияют на его работу.

## 7. Чтение, сохранение и обработка ошибок

Перед обработкой проверяется существование входного файла и успешность его чтения. Перед сохранением результата автоматически создаётся выходная директория, если она отсутствует. После сохранения проверяется, успешно ли записано изображение.

Функция `read_image` проверяет существование входного файла и загружает изображение с помощью `cv2.imread`. Если файл отсутствует, возникает `FileNotFoundError`. Если изображение не удалось прочитать, возникает `ValueError`.

Функция `save_image` создаёт родительскую папку для выходного файла и сохраняет результат с помощью `cv2.imwrite`. Если сохранить изображение не удалось, программа сообщает об ошибке.

В `main.py` выбранный фильтр создаётся через `ImageFilter.get_filter`. Затем к изображению применяется метод `apply` с параметрами, соответствующими выбранному фильтру. Ошибки чтения, некорректных значений и операций ввода-вывода перехватываются и выводятся пользователю.

## 8. Обоснование использования NumPy

Изображение является массивом чисел, поэтому многие преобразования можно выразить через операции над массивами:

- взвешенное сложение цветовых каналов;
- линейное смешивание изображения с цветом;
- преобразование яркости и цветовых каналов;
- применение двумерных масок;
- генерацию и добавление случайного шума;
- вычисление градиентов яркости;
- усреднение значений соседних пикселей;
- интерполяцию цветовых палитр по яркости;
- формирование нескольких слоёв свечения с разными масштабами размытия.

NumPy позволяет выполнять арифметические операции сразу над массивами, что уменьшает необходимость использовать циклы Python для обработки каждого пикселя.

OpenCV используется для чтения и записи изображений. Основные алгоритмы преобразования реализованы самостоятельно с использованием NumPy; готовые высокоуровневые фильтры OpenCV для этих преобразований не применяются.

## 9. Ограничения реализации

1. Метод ближайшего соседа может создавать ступенчатые границы при увеличении изображения.
2. Случайный шум, царапины и пыль могут отличаться между запусками.
3. Размытие в Neon является аппроксимацией гауссова размытия с помощью последовательных усредняющих проходов. Оно выбрано как самостоятельная реализация на NumPy и может отличаться от точного гауссова фильтра.
4. Параметры художественных эффектов предназначены для визуальной стилизации и не являются точной физической моделью фотоплёнки.
5. После вычислений значения цветовых каналов ограничиваются диапазоном от 0 до 255.
6. Для некоторых изображений параметры художественных эффектов могут требовать подбора: результат зависит от исходной яркости, контраста и композиции.

## 10. Вывод

В ходе работы разработана библиотека обработки изображений, включающая восемь фильтров. Для изменения размера используется индексирование массива по методу ближайшего соседа, для цветовых преобразований — линейные комбинации каналов, интерполяция цветовых палитр и смешивание пикселей, а для художественных эффектов — радиальные маски, случайные величины, локальное усреднение и градиент яркости.

В рамках доработки Antique дополнен радиальной виньеткой, в Matte реализовано управление радиусом центральной области, алгоритм Neon переработан с использованием нескольких слоёв свечения, а Film получил отдельную модель плёночной цветопередачи на основе преобразования яркости и интерполяции цветовых палитр.

Реализация демонстрирует, как базовые операции над матрицами изображений позволяют создавать геометрические, цветовые и художественные эффекты без использования готовых высокоуровневых фильтров OpenCV.
